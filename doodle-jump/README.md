# Doodle Jump (C# / MonoGame)

Вертикальный 2D-платформер в духе **Doodle Jump**: прыгайте по платформам вверх, уклоняйтесь от падения, набирайте очки.

## Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Влево |
| `→` / `D` | Вправо |
| `Space` / `Enter` | Новая игра (после **YOU DIED**) |
| `Esc` | Выход |

Игрок **автоматически отскакивает** при приземлении на платформу (если падает сверху). При падении за нижний край экрана — **YOU DIED** (как в Dark Souls).

## Типы платформ

- **Зелёные** — обычные
- **Голубые** — двигаются по горизонтали
- **Оранжевые** — ломаются после одного прыжка

## Монеты

- На платформах появляются **золотые монеты** (в начале — несколько штук, дальше — случайно).
- Счётчик вверху: `Coins: X/10`.
- Собрав **10 монет**, игрок делает **мега-прыжок** (~920 px вверх + сильный импульс), счётчик монет сбрасывается.

## Запуск

Нужны [.NET SDK](https://dotnet.microsoft.com/download) (8+) и поддержка DesktopGL (Windows / Linux / macOS).

```powershell
cd doodle-jump
dotnet run
```

Сборка релиза:

```powershell
dotnet build -c Release
```

## Структура проекта

```
doodle-jump/
├── Game1.cs           # игровой цикл, камера, отрисовка
├── Player.cs          # физика и управление
├── Platform.cs        # платформы и типы
├── PlatformSpawner.cs  # генерация платформ
└── Program.cs         # точка входа
```

Графика рисуется примитивами (без спрайтов) — проект легко расширить своими текстурами через `Content.mgcb`.
