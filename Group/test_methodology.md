## Эталонные ответы
Для каждого запроса сформирован эталонный ответ, соответствующий критериям:
* **Полнота** — содержит всю необходимую информацию.
* **Точность** — факты корректны и актуальны.
* **Читаемость** — текст структурирован и понятен.

Пример эталонного ответа для запроса №1 (финансовые):
> Налог на прибыль для ООО рассчитывается по формуле: (Доходы − Расходы) × 20 %. Доходы включают выручку от продаж и внереализационные доходы. Расходы должны быть документально подтверждены и экономически обоснованы. Ставка может быть снижена региональными законами до 13,5 %.

## Процедура тестирования
1. Система получает тестовый запрос.
2. Система генерирует ответ.
3. Сгенерированный ответ автоматически сравнивается с эталонным по метрикам ROUGE‑L, BLEU и BERTScore.
4. Результаты сохраняются в файл `results.csv`.

## Ожидаемые результаты
Количественные показатели качества генерации для каждого типа запросов и в целом по выборке.
