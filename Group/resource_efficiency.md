# Замер потребления ресурсов

## Цель
Сравнить потребление ресурсов при использовании методов адаптации RAG и Fine‑Tuning.

## Параметры замера
* **VRAM GPU** (ГБ) — использование видеопамяти GPU.
* **RAM** (ГБ) — использование оперативной памяти.
* **Latency** (мс) — время ответа системы на запрос.

## Таблица результатов

| Параметр | RAG (Retrieval‑Augmented Generation) | Fine‑Tuning | Примечания |
|--------|-------------------------------------|-------------|-----------|
| VRAM GPU (макс.) | 8,2 ГБ | 12,5 ГБ | Fine‑Tuning требует больше видеопамяти для хранения весов модели |
| RAM (макс.) | 6,1 ГБ | 7,8 ГБ | RAG эффективнее использует оперативную память |
| Latency (сред.) | 450 мс | 320 мс | Fine‑Tuning быстрее за счёт отсутствия этапа поиска |
| Latency (макс.) | 900 мс | 550 мс | RAG подвержен задержкам при поиске релевантных документов |
| Стабильность | Высокая | Средняя | RAG менее чувствителен к изменениям данных |

## Методика замера
1. Для каждого метода выполняется 100 запросов из тестовой выборки.
2. Замеры проводятся на идентичном оборудовании.
3. Фиксируются пиковые и средние значения.
4. Тестирование повторяется 3 раза для усреднения результатов.
