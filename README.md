В отличие от традиционных систем хранения результатов, семантическая модель экспериментов позволяет моделировать нелинейные зависимости между сущностями (тестами, параметрами, артефактами, этапами выполнения), учитывая контекст их взаимосвязей. Модуль предоставляет инструменты для автоматического построения цепочек зависимостей, контроля целостности тестовых данных и визуализации хода выполнения экспериментов в виде наглядных отчетов.
